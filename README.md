**sasaGo** — это современное и минималистичное веб-приложение (SuperApp), объединяющее ключевые сервисы городского ритма в единой экосистеме. 

## Сервисы в экосистеме

* **sasaТакси** — быстрый заказ поездок с выбором тарифов и фото водителей.
* **sasaСамокаты** — кикшеринг по всему городу с калькулятором стоимости и выбором минут.
* **sasaЕда** — быстрая доставка блюд из любимых ресторанов (*The Бык, Додо Пицца, Pho Bo Express* и др.).
* **sasaИнвест** — интерактивный калькулятор доходности и управление инвестициями.

---

## Ключевые особенности

- **Единая авторизация:** Авторизация и регистрация пользователей на сессиях (HTTP-Cookie) с SHA-256 хэшированием паролей.
- **Баланс «Sasa Плюс»:** Единый накопительный счет бонусов, обновляющийся в реальном времени во всех разделах.
- **Единый дизайн-код:** Современный оранжево-белый интерфейс, адаптивная сетка (Grid/Flexbox) и темные акценты.
- **Zero Dependencies:** Бэкенд написан исключительно на чистом Python без сторонних библиотек и тяжелых фреймворков.


## Технологический стек

* **Backend:** Native Python (`http.server`, `json`, `hashlib`, `uuid`, `urllib`).
* **Frontend:** Vanilla HTML5, CSS3 (CSS Variables, Flexbox, Grid), JavaScript (Fetch API, DOM manipulation).
* **Storage:** JSON-база данных (`users.json`) с защищенным хранением токенов и хэшей.
