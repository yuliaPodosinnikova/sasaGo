# SuperApp Экосистема: sasaGo 

**sasaGo** — минималистичное веб-приложение (SuperApp), объединяющее ключевые городские сервисы (Такси, Самокаты, Инвестиции и Еду) в единой экосистеме с единым балансом бонусов «Sasa Плюс» и собственной системой авторизации.

Интерфейс выполнен в едином **светлом оранжево-белом стиле** с адаптивной сеткой, фиксированной шапкой и карточками услуг.

## Основные возможности

- **Единая авторизация:** Сессионная система входа и регистрации через HTTP-cookie и хэширование паролей.
- **Единый баланс «Sasa Плюс»:** Пополнение и списание единого счета бонусов во всех сервисах.
- **Модульная структура:** Каждая утилита (Такси, Самокаты, Инвестиции) имеет свой интерфейс, но использует общую шапку, авторизацию и стилизацию.
- **Интерактивные калькуляторы:** Расчет стоимости поездок и планирование доходности инвестиций в реальном времени.

## Технологический стек

- **Backend:** Native Python (`http.server`, `json`, `hashlib`, `uuid`) — без внешних фреймворков и сторонних зависимостей.
- **Frontend:** Pure HTML5, CSS3 (Flexbox/CSS Grid, CSS Variables), JavaScript (ES6+ Fetch API).
- **Хранение данных:** Файловое хранилище `users.json` (SHA-256 хэширование паролей, сессионные токены).
