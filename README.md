# SuperApp экосистема: sasaGo 🍊

**sasaGo** — это веб-приложение-экосистема в стиле минималистичного SuperApp, объединяющая утилиты (Такси, Еда, Инвестиции) с единым балансом бонусов «Sasa Плюс» и собственной системой авторизации.

Интерфейс выполнен в чистом **светлом оранжево-белом стиле** с акцентом на центрированный макет и карточки сервисов.

---

## Технологический стек

- **Backend:** Native Python (`http.server`, `json`, `hashlib`, `uuid`) без внешних фреймворков и сторонних зависимостей.
- **Frontend:** Pure HTML5, CSS3 (CSS Grid/Flexbox), JavaScript (ES6+ Fetch API).
- **Хранение данных:** Файловое хранилище `users.json` с хэшированием паролей (SHA-256) и поддержкой сессий через HTTP-cookie.
